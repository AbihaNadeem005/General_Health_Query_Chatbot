# Task 4: General Health Query Chatbot using Large Language Model (LLM)

## Project Overview  
The goal of this task is to build a simple AI-powered health chatbot that can answer general health-related questions using a Large Language Model (LLM). The chatbot uses prompt engineering and safety filtering to generate safe, friendly, and informative responses.

---

## Objective
- Build a chatbot that answers general health-related questions  
- Use a pre-trained Large Language Model (LLM)  
- Apply prompt engineering to control model behavior  
- Implement safety filtering for harmful or sensitive queries  
- Create an interactive conversational system  

---

## Dataset Used
- Type: No traditional dataset used  
- Model Source: Hugging Face Transformers Library (Pre-trained Model)

Description:  
Instead of a dataset, this project uses a pre-trained Large Language Model:

- Model: Mistral-7B-Instruct  
- Source: Hugging Face Transformers Library  

The model is already trained on a large corpus of text data and generates responses based on user prompts.

---

## Tools & Libraries Used
- Python  
- Hugging Face Transformers  
- Mistral-7B-Instruct Model  

---

## Tasks Performed
- Installed and imported required libraries  
- Loaded a pre-trained Large Language Model  
- Designed a structured prompt using prompt engineering  
- Implemented a chatbot function for response generation  
- Added a safety filter for harmful queries  
- Created an interactive chatbot loop for user interaction  

---

## Models Applied
- Mistral-7B-Instruct (Pre-trained Large Language Model)  

No training was performed. The model was used directly for inference through prompt engineering.

---

## Key Results & Findings
- The chatbot successfully generates relevant health-related responses  
- Prompt engineering helps control response style and safety  
- Safety filter blocks harmful or sensitive queries  
- The model provides general health information but does not diagnose diseases  
- The system demonstrates how LLMs can be used for conversational AI applications  

---

## Limitations
- The chatbot does not provide medical diagnosis  
- Responses depend on pre-trained knowledge of the model  
- Requires internet and model access to run  

---

## How to Run the Project
- Install required libraries using pip  
- Run the Python file using terminal or VS Code  
- Type your question to interact with the chatbot  
- Type "exit" to stop the program    
  
---

## Conclusion
This project demonstrates the use of a pre-trained Large Language Model to build a simple health chatbot. It highlights the importance of prompt engineering and safety filtering in developing responsible AI applications.
